# Pixel Frame Fields (Oriented DensePose)

Per-pixel surface frames for people: DensePose correspondence (body part + template UV) together with a per-pixel
rotation, the orientation of the template surface at that pixel in the camera ("From Surface Points to Surface
Frames").

- `research/`: the code as it was run on the Isambard-AI cluster, laid out as `~/codes/wan` (`densepose/` model,
  training, evaluation and visualisations; `bedlam/` training-data rendering; `paper/` the paper sources;
  `slurm/` the job scripts; `results/` evaluation reports).
